📄 Abstract

BioNAFNet is a deep learning framework designed for low-light image enhancement using seven biologically-inspired retinal processing modules. Drawing inspiration from the human visual system — including rod and cone photoreceptor responses, lateral inhibition, and temporal adaptation — the architecture processes dark images through a multi-scale U-Net backbone enriched with novel attention and frequency-domain mechanisms.


A massive 154M-parameter Teacher model is distilled into a compact 24M-parameter Student model, achieving real-time performance (20.5 FPS) while exceeding state-of-the-art methods on the LOL dataset (25.23 dB PSNR, 0.862 SSIM). A complete desktop application, LOL Image Enhancer, demonstrates practical real-world deployment of the approach.


🎯 Objective

To design and implement a high-speed, biologically-inspired deep learning algorithm from scratch for restoring dark images, and build an intuitive desktop application for practical deployment.

⚠️ Problem Statement

Low-light images simultaneously suffer from sensor noise, severe color cast, detail loss, and poor contrast, demanding efficient and high-quality restoration for real-world use. Existing methods either produce artifacts or are too slow for practical deployment.

✅ Conclusion

BioNAFNet bridges the quality-speed gap in low-light image enhancement. By integrating biologically-inspired retinal mechanisms — including photoreceptor modeling, lateral inhibition, dual scotopic/photopic pathways, and Weber-Fechner perceptual loss — with knowledge distillation, it achieves superior generalization and real-time performance.


The compact 24M-parameter Student model retains 95% of the Teacher's quality while running at 4× the speed (20.5 vs 5.3 FPS). Combined with the LOL Image Enhancer desktop application, this solution is practical, efficient, and ready for real-world deployment.
